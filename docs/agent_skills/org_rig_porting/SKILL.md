# ORG rig porting

Use when an authorized SDK/source checkout, source scene, matching Maya runtime,
output directory, intended domain, and explicit tolerances are available.

Read the graph/Maya node reference, embedding/tooling APIs, decision guide, and
agent workflow. Discover the requested output/control cohort and audit closure.
Every dependency ends in a live input, proven constant, supported expression,
declared external boundary, or blocker.

Reuse exact/scoped nodes first. Use RBF, sampled, or sparse-linear contracts only
with separate validation observations and reported domains/residuals. Add a new
general-purpose primitive only with independent semantics and synthetic tests;
do not add source-specific wrappers to conceal extraction gaps.

Preserve controls/editable curves, wire typed/packed inputs explicitly, validate
graph compilation, compare intermediate values/matrices and final geometry,
exercise fractional times and relevant domains, and reopen a relocated package.
Test cache invalidation/rebuild and authoring when those modes are delivered.

Return graph/resource/output-map paths, verification evidence, residuals,
tested environments/domains, unresolved/excluded outputs, and replay commands.
Successful export or a still frame is not completion. Keep working source
identifiers and custom implementations out of public artifacts.
