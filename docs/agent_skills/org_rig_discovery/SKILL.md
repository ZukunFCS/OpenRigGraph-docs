# ORG rig discovery

Use for selecting the graph boundary of a requested character scene with an
existing ORG SDK and compatible Maya environment.

Read the node catalog, node reference, and agent porting workflow. Identify the
actual driven visible meshes, deformers, transforms, and animator-facing inputs.
Resolve source references/plug-ins before sampling. Trace backward from outputs;
do not select driven attributes as independent controls or confuse hidden
intermediate geometry with unrelated preview meshes.

Record replayable mesh/control/output selection, units/spaces, logical indices,
source-domain limits, resources, and unresolved dependencies. A current value
is not proof of constancy. Classify runtime gaps separately from exporter gaps,
deliberate external boundaries, and approximation choices.

Keep source identifiers/probes in private work packets. Use only independent
examples in public documentation. Return the selection manifest, closure audit,
blockers, and exact replay commands for the porting stage.
