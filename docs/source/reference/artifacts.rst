Port artifact glossary
======================

Graph JSON describes portable behavior. A compiled module caches its evaluation
program. Controller/output mappings preserve source correspondence and units.
Resource manifests declare relative paths, versions, layouts, and hashes.

Discovery manifests make output/control selection replayable. Source observation
rows are oracle data; fit rows and held-out verification rows have different
roles. Verification reports record tested domains, residuals, units/tolerances,
failures, exclusions, and replay commands. Status/agent packets summarize current
blockers but cannot replace checking the delivered graph and geometry.

Public examples are independent fixtures. Do not publish working scenes,
captures, source identifiers, or internal reports as tutorial data.
