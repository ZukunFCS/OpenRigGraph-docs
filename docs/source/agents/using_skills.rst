Use the discovery and porting skills
====================================

The documentation distribution includes reusable, source-neutral skill files:

* :download:`Discovery skill <../../agent_skills/org_rig_discovery/SKILL.md>`.
* :download:`Porting skill <../../agent_skills/org_rig_porting/SKILL.md>`.

Supply the documentation/SDK root, requested scene, matching mayapy/plug-in,
output directory, intended domain, and acceptance tolerances. Example assignment:

.. code-block:: text

   Read the ORG node reference and porting skill in the documentation bundle.
   Use my existing SDK and matching Maya environment to port the supplied scene.
   Preserve animator controls and editable curves. Record input/output ownership,
   units, spaces, unsupported dependencies, and a replayable verification packet.
   Do not treat successful export as proof of deformation/animation parity.

Review graph validation, output coverage, independent source comparisons,
approximation domains/errors, temporal behavior, authoring, and relocation.
Keep source-specific identifiers and probes in private working artifacts.
